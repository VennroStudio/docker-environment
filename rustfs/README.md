# RustFS

S3-совместимое хранилище RustFS в Docker-контейнере.

## Быстрый старт

```bash
make init
```

Команда создаст `.env` из `.env.example` (если его ещё нет), скачает образ и поднимет контейнер.

## Настройка `.env`

Перед первым запуском отредактируй `.env`:

| Переменная                            | Описание                                                                             |
|---------------------------------------|--------------------------------------------------------------------------------------|
| `PROJECT_NAME`                        | Название проекта                                                                     |
| `RUSTFS_ACCESS_KEY`                   | Логин для доступа к API и консоли                                                    |
| `RUSTFS_SECRET_KEY`                   | Пароль для доступа к API и консоли                                                   |
| `RUSTFS_CONSOLE_ENABLE`               | `true`/`false` — включить или отключить веб-консоль (порт 9001)                      |
| `RUSTFS_CONSOLE_CORS_ALLOWED_ORIGINS` | Домен, с которого разрешён доступ к консоли из браузера (CORS). `*` — разрешить всем |
| `RUSTFS_ADDRESS`                      | Адрес и порт S3 API внутри контейнера, по умолчанию `0.0.0.0:9000`                   |
| `RUSTFS_CONSOLE_ADDRESS`              | Адрес и порт веб-консоли внутри контейнера, по умолчанию `0.0.0.0:9001`              |

⚠️ Порты наружу не пробрасываются — доступ к контейнеру идёт через внешнюю Docker-сеть `proxy` (например, через nginx proxy manager, подключённый к той же сети).

## Команды Makefile

Полный список — `make help`.

| Команда | Действие |
|---|---|
| `make env` | Скопировать `.env.example` → `.env`, если `.env` ещё не существует |
| `make init` | Первичная инициализация: `.env` + pull + build + up |
| `make up` | Поднять контейнер |
| `make down` | Остановить и удалить контейнер |
| `make restart` | Перезапустить контейнер |
| `make logs` | Логи контейнера (последние 100 строк, live) |
| `make ps` | Статус контейнера |
| `make config` | Показать итоговый конфиг с подставленными переменными из `.env` |

## Данные

Данные хранятся в Docker volume `storage-rustfs` (не удаляются при `make down`).

Посмотреть volume:
```bash
docker volume inspect storage-rustfs
```

Удалить volume вручную (полная потеря данных):
```bash
docker volume rm storage-rustfs
```
