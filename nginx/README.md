# NPM (nginx proxy manager)

Reverse-proxy с веб-панелью управления для всех остальных сервисов.

## Быстрый старт

```bash
make init
```

Команда:
- создаст `.env` из `.env.example` (если его ещё нет),
- создаст внешнюю сеть (если её ещё нет),
- скачает образ и поднимет контейнер.

После запуска зайди на `http://localhost:${NPM_PORT}` с сервера или через SSH-туннель — стандартные учётные данные при первом входе:
- Email: `admin@example.com`
- Пароль: `changeme`

Панель сразу попросит сменить и то, и другое.

## Настройка `.env`

Перед первым запуском отредактируй `.env`:

| Переменная      | Описание                                                          |
|-------------------|---------------------------------------------------------------------|
| `PROJECT_NAME`  | Название проекта (влияет на префикс контейнера в Docker)           |
| `NETWORK`       | Имя внешней Docker-сети, к которой подключается контейнер          |
| `NPM_PORT`      | Локальный порт хоста для админ-панели NPM                          |

## Порты — здесь они нужны напрямую

В отличие от остальных сервисов в этом наборе, NPM **сам является входной точкой** для всего трафика — проксировать его больше некому, поэтому порты пробрасываются на хост напрямую:

- `80` — HTTP (в том числе для автоматического получения сертификатов Let's Encrypt)
- `443` — HTTPS
- `127.0.0.1:${NPM_PORT}` → `81` — админ-панель управления, доступна только с хоста или через SSH-туннель

## Данные

Хранятся в обычных папках на хосте (не в Docker volume):
- `./data` — конфигурация NPM (список прокси-хостов, пользователи и т.д.)
- `./letsencrypt` — выпущенные SSL-сертификаты

Бэкап — просто скопировать эти две папки. Они не удаляются при `make down`, но добавь их в `.gitignore`, если репозиторий публичный (там сертификаты и хэши паролей).

## Команды Makefile

Полный список — `make help`.

| Команда | Действие |
|---|---|
| `make init` | Первичная инициализация: `.env` + сеть + pull + up |
| `make up` | Поднять контейнер |
| `make down` | Остановить и удалить контейнер |
| `make restart` | Перезапустить контейнер |
| `make logs` | Логи контейнера (последние 100 строк, live) |
